# Сейчас

Один следующий шаг. Спокойный планировщик на русском: записать дело, начать, пройти маленькие шаги и вернуться после отвлечения. Без регистрации, оплаты, рекламы и аналитики.

**Статус:** первая версия опубликована: [открыть «Сейчас»](https://mnemonicsquare-cpu.github.io/I_HAVE_A_PLAN/). Проверены локальная сборка и GitHub CI: 47 unit + 18 E2E, typecheck, lint и production build. На фактическом HTTPS-сайте дополнительно прошли 17 E2E, включая основные действия, сохранение и офлайн. Подробности — [docs/QA.md](docs/QA.md).

## Что есть

«Сейчас», «Сегодня», «Позже»; быстрый ввод и черновики; шаги и пауза; перенос и безопасная последняя отмена; календарные повторения; напоминания в открытом приложении; «Я потерялся» с предпросмотром пересборки; JSON-копии с проверяемым восстановлением; отключаемые лисёнок, искры, звук и таймер; PWA с офлайн-работой после кэширования.

Содержание дел хранится в IndexedDB этого браузера. Другой браузер или телефон — отдельная база. Очистка данных браузера и ограничения хранения могут её удалить: регулярно скачивайте копию в настройках. Локальное хранение не является шифрованием. Дела не отправляются в URL, аналитику, GitHub или сервер; хостинг получает обычные запросы загрузки сайта.

## Локальный запуск

Нужен Node.js 24 (допустим совместимый Node ≥22.12).

```sh
npm ci
npm run dev
```

Откройте адрес, выведенный Vite, с путём `/I_HAVE_A_PLAN/`. Для проверки production:

```sh
npx playwright install chromium
npm run validate
npm run preview
```

Команды: `dev`, `build`, `preview`, `typecheck`, `lint`, `test`, `test:e2e`, `validate`. Последняя последовательно проверяет типы, lint, unit, production build и E2E; ошибка останавливает команду. На Linux перед E2E: `npx playwright install --with-deps chromium`. Результаты и ограничения — [docs/QA.md](docs/QA.md).

## GitHub Pages

Workflow `.github/workflows/pages.yml` проверяет каждый PR и обновление main. После успешных проверок main публикуется через официальные Pages actions и environment `github-pages`. Каталог dist не хранится в Git. Vite base, manifest, precache и worker используют `/I_HAVE_A_PLAN/`; прямые ссылки разделов — хеши, например `/#today` после пути приложения.

Владелец включает **Settings → Pages → Build and deployment → Source → GitHub Actions**. После этого запустите workflow «Проверка и публикация» или повторите его последнюю неуспешную публикацию. Успех проверяется по deploy и фактической HTTPS-странице, а не наличию репозитория.

## На телефоне и без сети

Обычная вкладка полностью поддерживается. Если браузер предлагает установку, используйте его меню. На iPhone в Safari: «Поделиться» → «На экран Домой». После завершения подготовки кэша основные экраны и действия работают офлайн. Обновление предлагается отдельно, без внезапного перезапуска активного дела. Черновик и база остаются на месте.

## Напоминания

**Напоминания работают, пока приложение активно. Когда оно закрыто, сигнал может не прийти.** Это не будильник: сигналы не гарантированы при блокировке телефона или приостановке браузера. Системные уведомления включаются отдельным действием после создания напоминания и только при поддержке браузера. Отказ не мешает работе. По умолчанию текст уведомления скрывает название дела. [Подробности](docs/REMINDERS.md).
