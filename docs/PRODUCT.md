# Продукт

«Сейчас» помогает записать намерение, увидеть одно понятное действие и вернуться после отвлечения. Приложение предназначено для русскоязычных взрослых, в том числе людей с СДВГ; эффективность именно этого продукта пока не исследована.

## Рабочие сценарии

1. Ввести название без настройки → сохранить в «Позже» → по желанию начать сейчас.
2. Выбрать сегодня/завтра/дату, при необходимости время, напоминание, шаги и повторение.
3. Начать → выполнить один шаг → следующий шаг → завершить. Пауза сохраняет время и шаги.
4. «Не могу сейчас» → упростить первый шаг, перенести или убрать из сегодняшнего плана.
5. «Я потерялся» → увидеть посильное предложение с переносами → подтвердить → вернуться к одному делу.
6. После перерыва продолжить сегодняшний день. Старое остаётся в необязательной группе «Раньше».
7. Скачать JSON → проверить копию → восстановить на другом устройстве с подтверждением замены.

## Границы первой версии

Три раздела, local-first, календарные повторения, активные напоминания, шаги, пересборка, настройки, резервные копии, PWA. Нет AI, регистрации, облачной синхронизации, сервера, социальных функций, статистики продуктивности, медицинских рекомендаций, платных функций или интеграций. Демоданные не добавляются автоматически. Удаление/завершение/перенос/пересборка имеют безопасную последнюю отмену. Звук и украшения необязательны.

## Приёмка

- Запись без предварительного планирования; обязательное поле только название.
- Одно объяснимое действие и возможность ручного выбора.
- Сохранение шагов, паузы и времени после перезапуска; атомарные действия.
- Нет стыда, штрафов, серий посещения, требований разобрать очередь.
- Закреплённые события не перемещаются пересборкой; конфликты видны.
- Неподходящий импорт не меняет базу; экспорт реально восстанавливает её.
- После кэширования основные действия доступны офлайн.
- Публикация проверяется отдельно от сборки и исходного кода.

Продуктовые гипотезы: полезный результат за минуту, снижение числа решений, буфер 5 минут, оценка неизвестного 15 минут, вместимость 70%, конец 21:00. Это изменяемые настройки, а не нормы способностей человека. Протокол проверки с людьми — в QA.md.
